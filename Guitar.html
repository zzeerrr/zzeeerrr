Perjalanan Saya Belajar Guitar

Saya mulai mempelajari guitar ketika duduk di kelas 9. Orang tua saya selalu mendorong saya untuk mencoba bermain musik, dan akhirnya saya memilih guitar sebagai alat musik pertama yang benar-benar saya seriusin.

Awalnya sulit, jari sakit, chord berantakan — tapi lama-lama saya mulai terbiasa dan mulai bisa memainkan banyak lagu. Semakin sering saya latihan, semakin besar rasa cinta saya pada permainan guitar.

Tidak lama setelah itu, saya mulai menunjukkan kemampuan saya dan akhirnya dipercaya untuk melayani sebagai pemain musik di gereja. Momen itu sangat penting bagi saya karena saya bisa menggunakan talenta yang saya pelajari untuk sesuatu yang berarti.

Bermain guitar telah menjadi bagian besar dalam hidup saya — tempat saya mengekspresikan diri, mengembangkan kreativitas, dan memberi dampak positif bagi orang lain.
